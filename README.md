## 📖 About

SafeRun is a **top-down roguelike** built in Unity 6, set inside a school overrun by bullies and cyberbullies. The player must navigate classrooms, hallways, and locker rooms — dodging, dashing, and fighting back using power-ups scattered across the map.

Beyond the gameplay, SafeRun carries a message: it raises awareness about **bullying and cyberbullying**, showing players that standing up for yourself and others is a real kind of strength.

> Developed as an academic project at **Universidad del Norte**, Barranquilla, Colombia — 2026.

---

## 🎮 Gameplay Features

| Feature | Description |
|---|---|
| 📄 **Paper Projectiles** | Launch paper balls at enemies using a physics-based projectile system |
| 💨 **Dash Mechanic** | Quick dodge to evade incoming attacks and reposition |
| ⭐ **Power-ups** | Collect stars in classrooms to unlock special attacks |
| 🪞 **Emotional Mirrors** | Reflect enemy attacks — a mechanic representing emotional resilience |
| 🏫 **School Levels** | Explore classrooms, hallways, and locker rooms with unique enemy layouts |
| 👾 **Roguelike Structure** | Variable enemy and power-up distribution keeps every run fresh |
